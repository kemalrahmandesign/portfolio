# Tests

An end-to-end suite that drives the real page in headless Chromium and checks
behaviour: the intro state machine, the take and the fast forward, the menu,
the prop labels, the overscroll, the scroll-driven sections, the cursor, and a
second lap through all of it (several bugs only ever appeared the second time).

It was written and grown over the first long working session, where it caught
most regressions before Kemal did. Last run: **61 passing, 0 failing.**

## Run it

```bash
python3 tests/build.py                    # writes tests/.site/ (gitignored)
cd tests/.site && python3 -m http.server 8099 &   # in the background
node tests/e2e.js                         # PASS / FAIL per line
node tests/mobile.js                      # phone: tap menu, tap a case study
node tests/pages.js                       # case pages and deep links
```

`build.py` swaps three things for limitations of the container, not of the
site: Google Fonts become the committed woff2 files in `tests/fonts/` (Chromium
here cannot reach Google Fonts and silently falls back, which ruins any width
measurement), `.mp4` clip paths become `.webm` stubs (Playwright's Chromium has
no H.264), and the missing clips and poster are generated by `stubs.js`.

The stubs are flat grey. **The suite tests behaviour, not pictures.** Nothing in
it says whether the site looks right; screenshots and Kemal's eyes do that.

## When a test fails

Suspect the harness before the feature. Twice in the first session a batch of
assertions failed together because the test had scrolled to positions that no
longer existed, or had already navigated back to the hero before measuring the
monitor sections. The behaviour was correct both times.

Timing assertions that sample one instant (for example "the wall covers at
540ms") race the page's own timers. Poll across a window instead.

## Screenshots

For looking at the page rather than testing it, Playwright screenshots work
normally. For WebGL, launch Chromium with
`--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader` and create
the renderer with `preserveDrawingBuffer: true`, or every screenshot of a
canvas comes back blank even while it is rendering correctly.

The fonts are Inter, Inter Tight, Kaushan Script, JetBrains Mono and
Instrument Serif, all under the SIL Open Font License. `build.py` also copies
`vendor/` (GSAP) into the test site.
